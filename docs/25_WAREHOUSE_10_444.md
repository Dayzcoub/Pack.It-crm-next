# 25. Warehouse decision 10.444 — невозвращённое оборудование

## Решение

Невозвращённое с мероприятия оборудование не списывается автоматически.

Если при возврате выявлена недостача, соответствующее количество остаётся в отдельном состоянии `outstanding/missing` до выяснения результата.

Такое оборудование:

- не считается доступным для новых резервов и выдач;
- не возвращается в `Ready`;
- не уменьшается из учёта через автоматическое списание;
- остаётся связано с исходной складской операцией/проектом как открытое расхождение.

## Закрытие расхождения

Допустимы два основных исхода:

1. Оборудование позднее вернулось — фиксируется отдельная операция возврата/закрытия расхождения, после чего оно снова участвует в обычном складском учёте согласно своему состоянию (`Ready` или `Blocked`).
2. Оборудование признано окончательно потерянным — создаётся отдельная явная операция списания. Только эта операция окончательно уменьшает `on_hand`.

## Архитектурные последствия

- `missing/outstanding` является складским исключением/состоянием расхождения, а не `ShortageCase`.
- `ShortageCase` создаётся отдельно только тогда, когда фактически доступного пригодного запаса недостаточно для подтверждённой потребности проекта.
- Это решение продолжает правила 10.432–10.435: применённые складские операции неизменяемы, а изменения состояния и списания оформляются новыми типизированными операциями.
- Нельзя компенсировать недостачу прямым редактированием остатка.

## MVP

Для MVP достаточно хранить открытое количество `outstanding/missing`, ссылку на исходную выдачу/возврат, проект/контекст и историю последующих операций. Отдельный сложный процесс расследования потерь не требуется.
