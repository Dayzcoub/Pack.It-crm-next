# 10.409 — Активное предложение, превышающее новый остаток нехватки

## Решение

Если после частичного принятия другого решения текущий остаток нехватки становится меньше количества в уже активном предложении, такое предложение не закрывается автоматически.

Оно остаётся активным, но получает состояние **«требует корректировки»**.

Пока количество в предложении превышает актуальный остаток нехватки:

- предложение нельзя принять;
- автор должен отредактировать количество до допустимого значения;
- предыдущая версия предложения сохраняется в истории согласно решению 10.403;
- тип решения при такой корректировке не меняется согласно 10.406;
- после сохранения корректировки новая версия сразу снова становится текущим активным предложением согласно 10.405;
- отдельное уведомление кладовщику о такой корректировке не требуется согласно 10.402.

## Архитектурная граница

Состояние применимости предложения к текущему остатку относится к bounded context `shortages`.

Это не создаёт складских, резервных или иных побочных эффектов само по себе. Побочные эффекты возникают только после успешного принятия решения соответствующим application use case.
