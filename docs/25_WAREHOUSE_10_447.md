# 10.447. Отдельная инвентаризация не входит в MVP

## Решение

В MVP PACK.IT CRM Next не вводится отдельный процесс полной или циклической инвентаризации склада.

Расхождения между фактическим и учётным количеством исправляются по мере обнаружения через явную складскую операцию корректировки (`inventory adjustment`).

## Правила

- Прямое редактирование текущего остатка запрещено.
- Любая корректировка количества должна быть оформлена как отдельная типизированная операция.
- Операция корректировки использует общий `WarehouseOperation` envelope и сохраняет автора, время, причину и контекст.
- Применённая корректировка неизменяема; ошибка в ней исправляется новой компенсирующей/корректирующей операцией.
- Отсутствие отдельного inventory-count workflow в MVP не меняет архитектурный инвариант: текущий остаток является следствием применённых складских операций, а не независимо редактируемым числом.
- Полноценные periodic/cycle count процессы могут быть добавлены позже без изменения базовой модели учёта.

## Связь с предыдущими решениями

Это решение продолжает 10.432–10.435: складские операции после применения неизменяемы, изменения остатка происходят только через явные операции, а не через CRUD-перезапись баланса.
