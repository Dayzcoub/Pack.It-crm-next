# Warehouse / Shortages — решение 10.403

## Решение

Активное предложение по нехватке можно редактировать без отзыва и создания нового предложения.

При сохранении изменений:

- текущее предложение обновляется до новой версии;
- предыдущая версия предложения сохраняется в истории;
- история должна позволять восстановить, какие значения и текст были до изменения;
- редактирование не создаёт новое отдельное предложение и не разрывает связь с исходным предложением;
- текущее состояние предложения после успешного сохранения считается актуальной версией для дальнейшего рассмотрения и принятия решения.

Это правило применяется, в частности, когда после частичного закрытия нехватки остаток стал меньше ранее предложенного количества и автор должен скорректировать предложение согласно решению 10.401.

История версий относится к домену `shortages`; значимые изменения также должны быть доступны для соответствующего аудита согласно общей архитектуре проекта.
