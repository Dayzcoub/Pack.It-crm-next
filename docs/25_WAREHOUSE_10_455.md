# 10.455 — Единый реестр местонахождения своего и субарендного оборудования

## Решение

В MVP используется **один общий реестр оборудования, находящегося вне обычного складского состояния**, без разделения на отдельные экраны для собственного и субарендного оборудования.

Каждая строка реестра должна явно показывать источник оборудования:

- `Наше` — оборудование принадлежит компании;
- `Субаренда` — оборудование получено от внешнего владельца/поставщика.

Для субарендного оборудования дополнительно обязательно хранится и отображается владелец/поставщик.

## Назначение реестра

Реестр отвечает на практический вопрос оператора:

> Где сейчас находится оборудование, сколько его там и кому оно принадлежит?

Он должен позволять видеть в одном месте, например:

- собственное оборудование на текущем мероприятии;
- собственное оборудование в долгосрочной аренде;
- собственное оборудование, временно находящееся у клиента/подрядчика;
- субарендное оборудование, находящееся на складе, на площадке или уже выданное на проект;
- количество по каждой позиции и текущий контекст местонахождения.

## Минимальные данные строки

Для MVP достаточно следующих данных:

- позиция оборудования;
- количество;
- источник: `Наше` / `Субаренда`;
- текущее местонахождение или контекст;
- проект/мероприятие, если применимо;
- у кого находится, если применимо;
- владелец/поставщик для субаренды.

Серийные номера не становятся обязательной частью этого реестра. Они по-прежнему используются только для точечных складских исключений, где необходимо идентифицировать конкретную единицу.

## Влияние на доступность

При расчёте доступности собственного оборудования учитывается только собственный парк компании.

Субарендное оборудование не увеличивает постоянное значение `Всего` для собственного парка. Оно является временным внешним ресурсом, связанным с соответствующим проектом/потребностью и жизненным циклом субаренды.

## Ограничение MVP

Не вводятся отдельные WMS-процессы, транспортные статусы, маршруты или многоуровневые складские локации. Общий реестр — это простой операционный инструмент для контроля фактического местонахождения оборудования в техпродакшне.
