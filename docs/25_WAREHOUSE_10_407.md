# Warehouse 10.407 — Причина изменения активного предложения

## Решение

При редактировании уже активного предложения отдельная причина изменения не требуется.

Достаточно сохранять в истории предложения предыдущую и новую версии, чтобы изменение оставалось прослеживаемым без дополнительного обязательного комментария.

## Правила

- редактирование активного предложения не требует отдельного поля `причина изменения`;
- предыдущая версия предложения сохраняется в истории;
- новая версия становится текущей активной версией в соответствии с решением 10.405;
- история должна позволять увидеть, какие данные были изменены между версиями;
- если для самого типа решения существуют обязательные комментарии или объяснения, их требования сохраняются и не отменяются этим решением;
- изменение типа решения по-прежнему запрещено решением 10.406: для другого типа требуется отзыв текущего предложения и создание нового.

## Архитектурная граница

Версионирование предложения и его история принадлежат bounded context `shortages`. Отдельное событие аудита только ради отсутствующей причины изменения не требуется, если иное не установлено общими правилами `audit` для значимых действий.
