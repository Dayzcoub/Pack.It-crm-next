# 10.450. Выданное оборудование не уменьшает общий парк компании

## Решение

Для MVP выдача оборудования на мероприятие не уменьшает количество оборудования, принадлежащего компании.

Операция `issue` меняет только текущее состояние доступности и местонахождения выданного количества:

- оборудование остаётся частью общего парка компании;
- выданное количество исключается из количества, доступного для новой выдачи/резервирования;
- после `return` это количество снова становится доступным, если оно не переведено в `Blocked` и не зафиксировано как `missing/outstanding`;
- списание уменьшает общий парк только отдельной явной операцией `writeoff`;
- недостача при возврате не уменьшает общий парк автоматически и обрабатывается по правилам 10.443–10.444.

## Терминологическое уточнение

Не следует смешивать понятия «принадлежит компании» и «физически находится на складе».

Продуктовое поведение этого решения соответствует варианту 2 из вопроса 10.450: выданное оборудование продолжает учитываться в общем количестве компании, но не входит в доступный остаток.

Для дальнейшей канонической модели количества нужно отдельно закрепить название общего количества компании и физически находящегося на складе количества, чтобы не перегружать термин `on_hand` нестандартным смыслом.

## Следствие для доступности

`available` не должно включать:

- выданное (`issued`) количество;
- `Blocked` количество;
- `missing/outstanding` количество;
- подтверждённые резервы в соответствии с правилами `reservations`.

Точная формула и названия количеств фиксируются отдельным решением.
