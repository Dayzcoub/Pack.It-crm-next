# 10.453. Долгосрочная аренда участвует в расчёте доступности

## Решение

Для MVP количество оборудования, находящееся в долгосрочной аренде, считается отдельным состоянием и автоматически уменьшает оперативно доступное количество для новых проектов.

Каноническая продуктовая формула доступности для планирования мероприятий:

```text
Доступно = Всего
           - Зарезервировано
           - На выезде
           - Неисправно
           - Missing
           - Долгосрочная аренда
```

При этом долгосрочная аренда не уменьшает общее количество оборудования, принадлежащего компании. Она только выводит соответствующее количество из оперативного пула доступности.

## Правила

- «Долгосрочная аренда» показывается пользователю отдельной строкой/состоянием.
- Количество в долгосрочной аренде остаётся частью общего парка компании.
- Это количество не может быть использовано при расчёте обеспечения новых проектов.
- Возврат из долгосрочной аренды выполняется вручную и снова увеличивает доступное количество.
- Для долгосрочной аренды в MVP не требуется обязательная дата возврата; обязательна только понятная привязка к месту/контрагенту по правилам 10.451–10.452.
- Если долгосрочно арендованное оборудование также помечено как `Blocked` или `Missing`, система не должна вычитать одну и ту же физическую единицу дважды; состояния должны интерпретироваться взаимоисключающе для расчёта количеств либо иметь детерминированный приоритет.

## Цель

Сохранить простую и понятную для техпродакшна модель: оборудование остаётся собственностью компании, но если оно надолго выведено из оперативного оборота, система автоматически не предлагает его для новых мероприятий.
