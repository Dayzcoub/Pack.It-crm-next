# 10.452. Долгосрочная аренда без обязательного периода

## Решение

Для MVP состояние оборудования «в долгосрочной аренде» не требует обязательных дат начала и планового возврата.

Хранится сам факт того, что оборудование выведено из оперативного пула, а также понятное пользователю указание, где или у кого оно находится.

Примеры пользовательского контекста:

- `в долгосрочной аренде у клиента X`;
- `на постоянной площадке Y`;
- `на объекте Z`.

## Правила

- оборудование остаётся частью общего парка компании;
- оборудование в долгосрочной аренде не участвует в расчёте оперативно доступного количества для новых проектов;
- обязательной даты возврата в MVP нет;
- система не должна автоматически возвращать такое оборудование в доступный пул по календарной дате;
- возврат в оперативный пул выполняется явным ручным действием пользователя;
- само состояние и последующее снятие этого состояния фиксируются в истории складских операций;
- если позднее появится реальная потребность в периодах аренды и плановом возврате, это может быть добавлено отдельным расширением без изменения базового смысла состояния.

## Контекст упрощённой складской модели

Это решение поддерживает принцип MVP для техпродакшна: склад нужен прежде всего для корректного планирования доступности оборудования, а не для воспроизведения полноценной WMS/ERP-модели.
